# Рабочие листы — прототип

Интерактивный прототип конструктора рабочих листов по макетам Figma ([Конструктор заданий → Рабочие листы](https://www.figma.com/design/w0Vo8bPSLIMq5IRIKbZkCo/?node-id=17209-64964)).

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173/

В правом нижнем углу — панель **«Экраны макета»** для быстрого перехода по всем состояниям.

## Основной сценарий

1. Главная → карточка **«Подготовить рабочий лист»**
2. Создание (генерация / вручную)
3. Лоадер «Думаю над темой»
4. Предпросмотр листа
5. Редактирование / блоки / ответы
6. Модалки: преобразование в задание, настройки, скачивание, дублирование, удаление, перегенерация

## Стек

React + Vite + TypeScript, токены и шрифт Onest из дизайн-системы макета.
